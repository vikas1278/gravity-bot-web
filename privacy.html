Privacy Policy.

How Gravity Bot collects, uses, and safeguards your server data.

1. Information We Collect

Depending on enabled features, Gravity Bot may process Discord identifiers such as user IDs, server IDs, channel IDs, role IDs, and bot configuration data.

2. Purpose of Data

Data is strictly used to execute commands, save server configurations, provide bot features, troubleshoot technical issues, and prevent abuse.

3. Data Sharing

We do not sell or monetize personal information. Data is only processed through necessary infrastructure (such as Cloudflare D1) to operate the service.

4. Retention & Deletion

We aim to retain only information reasonably required for bot operations. Server data can be removed when the bot is removed from the server.
